# Accessibility

Principles for making the studio's controls usable with assistive technology.

## Accessible Names

Every button, link and dialog has an accessible name.

- **Visible Text First**: a control is named by its visible text. A control that shows its text elsewhere, as a title or tooltip, reuses that text instead of a separate name.
- **Icons Are Decorative**: icons are hidden from assistive technology and never name a control. A control that shows only an icon carries an `aria-label`.
- **Label Inputs**: a reusable component that renders an icon-only control takes its name as a `string` input: `ariaLabel` when it names the component's own control, `<purpose>Label` when it names one of several inner controls.
- **One Name Per Concept**: a control that opens a dialog reuses the dialog's headline.
- **New Controls**: a new icon-only control takes its label input from the start.

---

## Nesting

A button or link never contains another button or link. The inner control is unreachable for assistive technology, and both report the same name. A component that wraps projected content in its own control lets the caller opt out when that content is already a control.

---

## Dialogs

An open dialog is exactly one dialog: one element with `role="dialog"` and `aria-modal="true"`, named by its headline. Layers that position or animate it add no role.

---

## Target Size

Every pointer target is at least 24 × 24 CSS px (WCAG 2.2, 2.5.8).

- **Icon Buttons**: a control around a small icon takes `min-width` and `min-height` of `24px`.
- **Spacing Exception**: a smaller target passes when a 24px circle centered on it meets no other target.

---

## Verification

- **Aria Snapshot**: `browser_snapshot` of the `playwright` MCP server lists each control of the served studio with its name. A control without a name shows as `button` or `dialog` alone.
- **Hidden Elements**: an element hidden with `visibility: hidden` or `display: none` is outside the accessibility tree and needs no name.
- **Nested Controls**: `document.querySelectorAll('button button, button a[href], a[href] button, a[href] a[href]')` on the rendered page returns no element.
- **Nested Dialogs**: `document.querySelectorAll('[role="dialog"] [role="dialog"]')` on an open dialog returns no element.
- **Review**: the `ux-patterns` MCP server reviews a component for accessibility, see **MCP Servers** in [`impl/ai-harness.md`](ai-harness.md#mcp-servers).
